# Projeto Blog Post 🔤
Este repositório contém o código do projeto Blog Post criado durante o curso **The HTML & CSS Bootcamp 2026 Edition** da Udemy, com auxílio do instrutor Colt Steele.  
O projeto simula a interface de um blog simples sobre tipografia no âmbito de desenvolvimento Front-End.

## Tecnologias utilizadas 💻
* HTML
* CSS
